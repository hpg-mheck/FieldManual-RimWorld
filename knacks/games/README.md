# Game Knacks

This area holds knacks for building content for specific games. Game
behavior changes with each release, so every game's index states the
version it was reviewed against and the date of that review.

## Games

- [RimWorld](rimworld/README.md) — mods for RimWorld 1.6: XML defs, C#
  against the game's assembly, patches, in-game testing, tooling, and
  showcases

Load a game's index first and follow its load order. Pair these knacks
with FieldManual's language-neutral standards and the stock knacks each
game's index names, such as FieldManual `knacks/games/steam/` for a
game sold through Steam. Paths written as FieldManual `knacks/<path>` are
inside a FieldManual checkout.
